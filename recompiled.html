Project Overview

The goal of Recompiled was to create a rogue-like first-person shooter. Developed as a class project for implementing AI systems into games. We implemented an AI director that adapted to the player's play style. So the game’s antagonist wasn’t merely a boss at the end of the level, but the “system” itself.

The narrative centers on "The Director," an artificial super-intelligence that has taken over a robot factory. Developing the game revolves around implementing an AI system that monitors the player’s actions, identifies their playstyle (Stealth, Ranged, or Fighter), and strategically spawns enemies to counter that style. It also leverages Unreal Engine 5's capabilities to create a visually appealing game.

Game Features

  • Adaptive AI Director: A system that tracks damage metrics (melee vs. ranged vs. stealth) to classify the player into a specific archetype and formulate a counterstrategy.
  • Dynamic Spawning: The Director is aware of the environment and uses "High" and "Low" spawn points, placing ranged enemies on elevated platforms to disadvantage the player.
  • State Tree Architecture: The entire Director logic is implemented as a State Tree, managing complex transitions between combat waves, challenge subwaves, and cooldown states.
  • Risk/Reward Challenges: Players initiate challenges to obtain cores, with performance graded on speed and health retained; high performance (Tier 1) grants a 90% chance of receiving a "Lucky" buff.

Challenges

Unreal Engine has a steep learning curve, so getting started was slow because features were not always as intuitive to implement as I would expect in code. We used Blueprint for this project because it was previously used in class and helps visualize Unreal Engine’s systems more effectively than standard code. Making a game is a challenge at every step. Coming up with theming, map layout, and system functionality. Then, creating a coherent map, implementing the character and its systems, and debugging.

Creating the AI Director was tricky, having a truly "balanced" difficulty was a real challenge. Often, limitations in player-metric collection could lead to edge cases. If a player attempted a stealth approach but was spotted at the last second, the model would register it as standard combat damage, thereby skewing the Director's data. Another struggle was tuning the difficulty for different skill levels. Since the Director is designed to exploit weaknesses, good players might find a counter, and the scenarios would never be sufficient to stop them, whereas unfamiliar players could find the counter-strategies overwhelming.

Ultimately, it all boiled down to working as a team to learn and understand Unreal Engine while confronting the challenges of implementing our ideas, debugging, and creating other parts of the game simultaneously.

Learning Outcomes

This project was a great opportunity to work with AI logic within Unreal Engine. I gained significant experience using Unreal Engine and its tools to create maps, enemies and game systems. Gaining a lot more experience with the benefits and limitations of Blueprint, along with the widgets, state trees and all the small things to just function in Unreal.

I benefited substantially from working with mechanisms such as state trees for global game management and data-driven gameplay, specifically from learning to convert raw inputs, such as "damage dealt" and "player location," into meaningful gameplay changes. It taught me how to work in Unreal and that creating a "smart" AI isn't just about its complexity. It is a lot about weighing and managing parameters to ensure that the AI makes decisions that appear fair and intuitive to the player.
