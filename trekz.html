Project Overview

TREKZ is a social-map web app for travellers to log, track, and showcase their trips.

It fills a gap between Instagram (visual but not structured) and Strava (tracking but not narrative).

Check out the LinkedIn blog post for more info!

Prototype Features

  • Trip logging with locations, photos, and notes
  • Visual map with pins
  • Search and filter functions (likes, views, recency)
  • Social elements like likes and comments
  • Clean, futuristic UI with smooth transitions (ties to the gallery screenshots)

Challenges

The class environment came with strict time constraints, which forced our team to not only generate an idea but also design and develop it within a very short window. While the project relied heavily on AI tools, these often produced imperfect layouts or styling that required manual refinement. As the sole programmer, I had to quickly diagnose and resolve errors that the AI could not detect or fix, all under time pressure. This process highlighted the need to balance AI-driven speed with human creativity and oversight.

We had to scale down the scope of the prototype significantly. We had intended to implement a functioning backend with user profile creation and authentication using Supabase, but had to cut it at the last minute. Some other ideas we wanted to implement but did not have time to were, having AI-generated captions/summaries for users that did not create them, integration with Instagram, having a complete mobile UI and collaborative trip creating.

Learning Outcomes

Deepened skills in interdisciplinary collaborative development, design, and presentation. Combining AI automation with manual problem-solving. Reinforced understanding of rapid prototyping, storytelling in UX, and travel-focused user engagement.
